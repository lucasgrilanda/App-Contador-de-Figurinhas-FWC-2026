⚠️ Microfone não funciona?

O Safari iOS exige HTTPS para microfone em rede WiFi. Opções:

1. USB + iTunes (mais simples): conecte o iPhone ao computador via cabo, faça port forward no iTunes → acesse pelo Safari:
http://localhost:8080/FigurinhaOp_iPhone.html

2. ngrok (WiFi sem cabo): no computador execute:
ngrok http 8080
Use o link https:// gerado pelo ngrok no Safari do iPhone.

3. Mesma rede WiFi (pode funcionar em iOS mais antigo):
http://[IP-DO-COMPUTADOR]:8080/FigurinhaOp_iPhone.html
